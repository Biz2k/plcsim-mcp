# Передача разработки: с чего начать

Разработка MCP-сервера PLCSIM Advanced ведется по стандартам `tiaportal-mcp`.

## Порядок работы

1. Прочитать основной план `../PLAN.md` и `../../TODO.md` в корне.
2. Разработка ведется в `src/PlcSimMcpServer`. Все инструменты располагаются в `ModelContextProtocol/PlcSimServer.Tools.cs`.
3. При реализации сложной логики (в особенности сетевой) сверяться с проектом [PLCsim-Advanced-Manager](https://github.com/jasperdekeuk/PLCsim-Advanced-Manager) (он предоставляет хорошие примеры вызовов API Siemens.Simatic.Simulation.Runtime.Api).

## Задачи
Статус: `[ ]` не начата, `[~]` в работе или сделана частично, `[x]` сделана.

- [x] **1. Жизненный цикл инстансов** (Создание, удаление, список).
- [x] **2. Состояние инстансов** (Включение, выключение, RUN, STOP).
- [ ] **3. Работа с тегами** (Чтение, запись, обновление списка).
- [ ] **4. Пакетная работа с тегами** (`batch_read`, `batch_write`).
- [ ] **5. Настройка сети** (Сложная логика маппинга и IPSuite).

Если возникают сложности с API, следует обращаться к официальному PDF-руководству `docs/s7-plcsim_advanced_function_manual_API_en-US_en-US.pdf`.
