## Основные направления разработки (TODO)

1. **Жизненный цикл инстансов (Instances)**
   - Реализовать список, создание (с проверкой типа), удаление инстансов.

   - Сохранение/восстановление состояния (профили).
6. **Виртуальная память (SD Card)**

## ⚠️ Известные проблемы (Known Issues)
- **Зависание UI при работе через API:** Выполнение частых вызовов к API (особенно быстрое удаление множества инстансов) при открытом графическом окне `PLCSIM Advanced User Interface` может вызвать состояние гонки (race condition) во внутренних обработчиках событий UI. Из-за этого графический интерфейс зависает.
- **Отказ запуска UI (Ghost State):** Если пользователь принудительно закрывает зависший UI, в памяти могут остаться "осиротевшие" куски симулятора (`S7PLCSIMV21.exe`) и вспомогательные службы, а также `PlcSimMcpServer` может удерживать API. Последующие попытки запустить UI будут безуспешны.
  - **Решение:** Для восстановления работоспособности необходимо убить все осиротевшие процессы: `taskkill /F /IM S7PLCSIMV21.exe` и `taskkill /F /IM Siemens.Simatic.Simulation.Runtime.Manager.exe`. Также обязательно нужно перезапустить MCP-сервер, чтобы он отпустил IPC-канал. После этого UI запустится штатно.
