# План работ

Состояние на 10.10.2026: Проект `plcsim-mcp` выделен из основного `tiaportal-mcp` и выпущен релиз (v0.2.0). Базовый функционал, работа со временем, пошаговая симуляция и аппаратные прерывания полностью завершены.

В будущем проект планируется объединить обратно в «TIA Portal AI Engineering Toolkit», так что стиль и структура должны совпадать с `tiaportal-mcp`.

## Текущие задачи (Технический долг и слабые стороны)

**Шаг 1: Инструмент очистки среды (Host Repair)**
- Создать инструмент `plcsim_host_repair` для принудительного завершения процессов `S7PLCSIMV21.exe` и `Siemens.Simatic.Simulation.Runtime.Manager.exe`.
- Разработать способ обработки `AccessViolationException` (изоляция или песочница), чтобы непредвиденные падения API Siemens не убивали процесс MCP-сервера.

**Шаг 2: Умный парсер сложных типов данных**
- Реализовать метод пакетного чтения блоков памяти с маппингом на структуру (по аналогии с тем, как это делает TIA Portal).
- Снизить оверхед на множественные вызовы JSON-RPC при чтении вложенных UDT и массивов.

**Шаг 3: Оптимизация производительности**
- Минимизировать накладные расходы при вызове инструментов.
- Подготовить архитектуру к поддержке стриминга данных (Data Streaming) для высокоскоростного опроса тегов.

## Идеи для дальнейшего развития (Vision)

**Развитие в рамках симуляции (Digital Twin & Co-Simulation)**
- **Высокоскоростной стриминг данных:** gRPC или WebSocket канал для обмена данными с физическими движками (Unity/Unreal Engine) в реальном времени.
- **Fault Injection (Симуляция отказов):** Генерация аварий на уровне модулей (КЗ, обрыв сети PROFINET) для тестирования логики диагностики ПЛК.
- **Multi-PLC коммуникация:** Инструменты для настройки и тестирования связи между несколькими виртуальными ПЛК (S7-Routing, PUT/GET).

**Автоматизация тестирования (CI/CD)**
- **End-to-End HMI Testing:** Интеграция с WinCC (через отдельный MCP-сервер или UI Automation) для проверки реакции интерфейса на изменение логики или аварии в симуляторе.
- **AI Scenario Runner:** Встроенный инструмент для запуска JSON-сценариев тестирования (установка входов -> ожидание -> проверка выходов).
- **Snapshot-тестирование:** Быстрое сохранение и восстановление состояния ПЛК для мгновенного перезапуска тестов без перегрузки проекта.

**Удобство для человека**
- **Web Dashboard:** Встроенная в MCP-сервер веб-страница на ASP.NET Core для визуального мониторинга виртуальных контроллеров и логов работы ИИ.
- **Кросс-серверная интеграция:** Тесное взаимодействие с `tia-mcp-server` для автоматического извлечения адресов памяти и бесшовной загрузки (Hot Reload).

## ⚠️ Известные проблемы (Known Issues)
- **Зависание UI при работе через API (Ghost State):** Выполнение частых вызовов к API при открытом графическом окне `PLCSIM Advanced User Interface` может вызвать состояние гонки. 
  - **Ручное Решение:** убить процессы `S7PLCSIMV21.exe` и `Siemens.Simatic.Simulation.Runtime.Manager.exe`, перезапустить MCP-сервер. 
  - **В планах:** Инструмент `plcsim_host_repair` (см. Шаг 1).
