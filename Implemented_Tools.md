# Инструменты MCP-сервера PLCSIM Advanced

## Жизненный цикл инстансов
- `plcsim_get_instances`: Получить список всех зарегистрированных инстансов.
- `plcsim_get_supported_cpus`: Получить список доступных типов процессоров для создания инстанса.
- `plcsim_create_instance`: Создание нового виртуального контроллера с выбором типа CPU.
- `plcsim_delete_instance`: Удаление виртуального контроллера.
- `plcsim_deploy_instance`: Автономное развёртывание инстанса (включая создание, привязку сети, настройку IP и включение питания в один шаг).

## Управление состоянием
- `plcsim_instance_control`: Управление состоянием виртуального контроллера (поддерживает действия `PowerOn`, `PowerOff`, `Run`, `Stop`, `MemoryReset`).

## Настройка сети
- `plcsim_set_global_network_mode`: Выбор режима глобальной сети симулятора (Local / VirtualEthernetAdapter).
- `plcsim_get_pc_interfaces`: Получить список доступных сетевых адаптеров хоста.
- `plcsim_set_instance`: Настройка сетевых параметров инстанса (привязка интерфейса, настройка IP-адреса, маски и шлюза).

## Работа с тегами
- `plcsim_list_tags`: Вывести список всех тегов, доступных в симуляции.
- `plcsim_refresh_tags`: Принудительно обновить список тегов из симуляции (если программа ПЛК была изменена).
- `plcsim_read_tag`: Чтение значения конкретного тега по его имени.
- `plcsim_write_tag`: Запись значения в тег (поддерживает автоматическое приведение типов, включая BCD, Time).
- `plcsim_batch_read`: Одновременное чтение нескольких тегов.
- `plcsim_batch_write`: Одновременная запись в несколько тегов (оптимизировано для большого объема).

## Снимки памяти (Profiles / Virtual SD Card)
- `plcsim_save_profile`: Сохранение текущего состояния ПЛК в профиль/архив.
- `plcsim_load_profile`: Восстановление состояния ПЛК из ранее сохраненного профиля.
- `plcsim_list_profiles`: Получить список всех доступных профилей.
- `plcsim_delete_profile`: Удалить сохраненный профиль.
- `plcsim_update_profile`: Обновить (перезаписать) существующий профиль.

## Глобальное управление
- `plcsim_connect`: Подключение к API PLCSIM Advanced.
- `plcsim_host_control`: Управление самим процессом PLCSIM Advanced на Windows (Запуск `Start`, Остановка `Stop`, Проверка `IsRunning`).
- `plcsim_cleanup_memory`: Вызов сборщика мусора и освобождение неиспользуемой памяти менеджера симулятора.
- `plcsim_get_logs`: Получение внутреннего лога MCP-сервера.
- `plcsim_get_mcp_settings`: Просмотр настроек MCP-сервера.
- `plcsim_set_mcp_settings`: Изменение настроек MCP-сервера.
