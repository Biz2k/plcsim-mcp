# Работа с типами данных в PLCSIM Advanced MCP Server

Взаимодействие с симулятором PLCSIM Advanced накладывает ряд ограничений на использование типов данных. В отличие от TIA Portal, API симулятора общается только через примитивные типы (`EPrimitiveDataType`). 

Ниже описаны правила для AI-агентов, как работать с различными типами данных в TIA Portal через наш сервер.

## 1. Базовые (Примитивные) типы
Для базовых типов данных (`Bool`, `Int8`, `Int16`, `Int32`, `Float`, `Double` и т.д.) используйте их напрямую. При вызове `plcsim_write_tag` сервер сам спарсит строковое значение в нужный тип, если вы передадите `dataType`.
- **Пример**: `value: "True", dataType: "Bool"`
- **Пример**: `value: "14.5", dataType: "Float"`

## 2. Строки (String / WString)
Хотя в API Siemens строки состоят из массива байт/символов и отдельного заголовка (Max Length, Actual Length), наш MCP-сервер **инкапсулирует** эту сложность.
- Для работы со строками используйте встроенную обработку.
- Обязательно указывайте `dataType: "String"` или `dataType: "WString"`.
- **Запись**: `plcsim_write_tag(tagName="MyTag", value="Hello", dataType="String")`
- **Чтение**: `plcsim_read_tag` со спецификацией типа `String` или `WString` сам прочтет байты и вернет текст.

## 3. Время (Time, LTime, S5Time)
В контроллерах Siemens тип `Time` хранится как `Int32` (миллисекунды), а `LTime` как `Int64` (наносекунды).
- Наш MCP-сервер поддерживает парсинг человекочитаемого формата Siemens Time (например: `10s`, `1h20m`, `500ms`).
- Для записи передавайте строку со временем и обязательно указывайте `dataType: "Time"`. Сервер сам переведет `10s` в `10000` и запишет как `Int32`.
- **Пример**: `value: "1h20m", dataType: "Time"`

## 4. BCD (Binary Coded Decimal) / Hex
Формат BCD (часто используется в старых проектах S7-300/400 и 7-сегментных индикаторах) не имеет встроенного типа в API. Он хранится в `Word` (`UInt16`) или `DWord` (`UInt32`).
- Вы должны **самостоятельно конвертировать** десятичное число в BCD (шестнадцатеричное представление) перед отправкой.
- Например, чтобы записать значение `123` в BCD:
  - Формируем Hex-строку: `0x0123`
  - Переводим Hex `0123` в десятичное число `291`.
  - Записываем в контроллер `291` с типом `UInt16`.
- Аналогично при чтении: получив от ПЛК `291`, вы должны перевести его в hex (`0x0123`) и интерпретировать как десятичное `123`.

## 5. Структуры (Struct, UDT)
API PLCSIM Advanced **не поддерживает** чтение/запись целых структур (`Struct` / `UDT`) единым вызовом.
- Вы должны обращаться к полям структуры индивидуально.
- Доступ осуществляется через точку: `MyStruct.Member1`, `MyMotor.Status.Running`.
- Для оптимизации используйте инструменты пакетного обмена: `plcsim_batch_read` / `plcsim_batch_write`, передавая туда список имен тегов.

## 6. Массивы (Array)
Аналогично структурам, массивы нельзя прочитать или записать целиком одним тегом.
- Индексируйте элементы массива индивидуально, используя квадратные скобки: `MyArray[0]`, `MyArray[1]`.
- Для обмена крупными массивами используйте `plcsim_batch_read` и `plcsim_batch_write`.
