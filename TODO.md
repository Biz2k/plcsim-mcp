# Проект `plcsim-mcp`

## Описание
Этот проект представляет собой отдельный MCP-сервер (Model Context Protocol), предназначенный исключительно для работы с **PLCSIM Advanced API**. 
Он выделен в отдельный репозиторий из основного сервера `tiaportal-mcp`, так как PLCSIM Advanced является самостоятельным продуктом Siemens и не требует TIA Portal Openness API. 

В качестве источника примеров использования PLCSIM API выступает проект [PLCsim-Advanced-Manager](https://github.com/jasperdekeuk/PLCsim-Advanced-Manager).

## Текущее состояние
- **Структура проекта:** Создана на базе `TiaMcpServer`. Удалены все зависимости и пространства имён, связанные с TIA Portal (Openness).
- **Платформа:** .NET Framework 4.8 (x64).
- **Библиотека API:** Проект успешно ссылается на `Siemens.Simatic.Simulation.Runtime.Api.x64.dll` (находится в папке `Libs/`).
- **Сборка:** Проект компилируется и работает как базовый MCP-сервер (stdio).
- **Заготовки инструментов:** В файле `src/PlcSimMcpServer/ModelContextProtocol/PlcSimServer.Tools.cs` находятся базовые заглушки команд (create_instance, power_on, read_tag и др.), которые необходимо реализовать.
- **Git:** Репозиторий привязан к [https://github.com/Biz2k/plcsim-mcp](https://github.com/Biz2k/plcsim-mcp) и базовая структура отправлена в ветку `master`.

## Предстоящие задачи (TODO)

### 1. Жизненный цикл инстансов (Instances)
- [ ] **Список инстансов:** Реализовать инструмент для получения списка всех зарегистрированных виртуальных контроллеров.
- [ ] **Создание инстанса (`plcsim_create_instance`):** Создание нового виртуального контроллера с выбором типа CPU (CPU1500, CPU1200 и т.д.).
- [ ] **Удаление инстанса (`plcsim_delete_instance`):** Безопасная остановка и удаление виртуального контроллера.

### 2. Управление состоянием (Power / Operating State)
- [ ] **Power On / Power Off:** Инструменты для включения и выключения питания виртуального ПЛК.
- [ ] **Run / Stop:** Перевод ПЛК в режим выполнения программы или остановки (`plcsim_run`, `plcsim_stop`).
- [ ] **Memory Reset (MRES):** Сброс памяти виртуального контроллера.

### 3. Настройка сети (Networking)
- [ ] **Конфигурация интерфейсов:** Настройка связи виртуального ПЛК (Virtual Ethernet Adapter, TCP/IP).
- [ ] **IP Маппинг:** Привязка виртуальных IP-адресов ПЛК к реальным сетевым адаптерам (опираясь на опыт `PLCsim-Advanced-Manager`).

### 4. Работа с тегами (Tag Access)
- [ ] **Чтение/запись (Single):** Чтение и запись значений конкретных тегов по их имени.
- [ ] **Пакетное чтение/запись (Batch):** Реализация инструментов для одновременного чтения/записи списка тегов для оптимизации скорости (`plcsim_batch_read`, `plcsim_batch_write`).

### 5. Снимки памяти (Snapshots)
- [ ] **Создание снимка:** Сохранение текущего состояния ПЛК в файл.
- [ ] **Загрузка снимка:** Восстановление состояния ПЛК из ранее созданного файла.

### 6. Виртуальная память (Virtual Storage / SD Card)
- [ ] Управление виртуальной картой памяти (создание, очистка, монтирование).

## Памятка для ИИ (AI Onboarding)
Когда вы возвращаетесь к работе над этим проектом, начните с просмотра:
1. `src/PlcSimMcpServer/Program.cs` — для понимания инициализации MCP сервера.
2. `src/PlcSimMcpServer/ModelContextProtocol/PlcSimServer.Tools.cs` — здесь должны располагаться все инструменты MCP (методы с атрибутом `[McpServerTool]`).
3. При реализации сложной логики (особенно сетевого маппинга) обращайтесь к локальному клону `PLCsim-Advanced-Manager-Clone`, чтобы подсмотреть, как работает `Siemens.Simatic.Simulation.Runtime.Api`.
